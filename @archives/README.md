# Archives

This directory contains historical files from the Typography API project development.
These files are preserved for reference but are no longer actively used.

## Contents

### Root Files

- **TYPOGRAPHY-PUBLIC-API-PROPOSAL.md** - Original project proposal (implemented Dec 2025)
- **index.html** - Outdated redirect to public/index.html (public directory removed Dec 2025)

### data/

Intermediate data files generated during Phase 1 and Phase 2 development:

- `cleanup-log.json` - Log of naming normalization changes
- `corrections-mapping.json` - Weight/style standardization mappings
- `naming-analysis.json` - Analysis of original naming inconsistencies
- `conversion-queue.json` - Queue for web format conversion (completed)
- `web-fonts-analysis.json` - Analysis of font sizes and compression
- `manual-review-queue.json` - Fonts flagged for manual category review

### docs/

- `PHASE-2-WEB-FORMATS.md` - Phase 2 planning document (completed)

## Active Files

For current project files, see:
- `/data/fonts-api-db.json` - Active API database
- `/data/fonts-metadata.json` - Font metadata
- `/data/font-categories.json` - Category assignments
- `/STATUS.md` - Current project status
